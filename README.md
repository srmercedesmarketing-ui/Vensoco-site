# vensoco.com

Sitio estático de Vensoco — landing bilingüe (ES/EN) con los formularios de registro.

## Estructura

- `index.html` — versión en español (raíz, vensoco.com)
- `en/index.html` — versión en inglés (vensoco.com/en/)
- `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` — íconos

No hay paso de build. Netlify publica este repo directo: **Build command: (vacío) · Publish directory: /** (raíz del repo).

## Deploy

Conectado a Netlify vía Git. Cualquier push a `main` dispara un deploy automático a vensoco.com — no hace falta subir archivos a mano.
